# Словобой: скоростная печать

Самодостаточная браузерная словесная игра без сборки и зависимостей.

Откройте `index.html` в браузере или запустите локальный сервер из этой папки:

```sh
python3 -m http.server 8080
```

Затем перейдите на `http://localhost:8080`.

При запуске игра сначала показывает выбор тематической колоды. Для просмотра production-интерфейса локально добавьте к URL `?production=1`. Чтобы оставить панель разработчика на удалённом хосте, используйте `?dev=1`.

## Текущий релиз

- В production игроку доступна «Скоростная печать» — основной режим игры «Словобой: скоростная печать».
- «Звездопад» уже реализован в исходниках, но его переключатель находится в панели разработчика и пока скрыт от игроков в production.
- Текущий релиз заявлен только для десктопа. Мобильные платформы и портретную ориентацию не указывайте в карточке до отдельного обновления.
- План вывода выбора режимов, мобильной версии и следующего обновления находится в [ROADMAP.md](ROADMAP.md).

## Правила прототипа

- Блоки с введённым словом удаляются, если образуют непрерывную линию слева направо или сверху вниз.
- В базовом режиме словарь не проверяется: засчитывается любая последовательность, которая действительно находится на поле.
- Блоки со звёздочкой при удалении прибавляют звезду к цели раунда.
- После удаления блоки падают, свободные места заполняются новыми буквами. Минимум слов — цель поля: игра не переписывает существующие клетки, чтобы её достигнуть. Если на поле совсем не осталось слов из словаря, оно целиком пересобирается с уведомлением.
- Кнопка «Добавить запрет» показывает будущий модификатор: слова с выбранной буквой временно нельзя использовать.
- В блоке «Для разработчика» можно выбрать минимум из 3, 5 или 7 слов на поле. Смена настройки начинает новый раунд.
- Там же отображаются известные слова, которые сейчас есть на поле. Игроку доступна лампочка: она кратко подсвечивает только первую букву одного из слов.
- «Журнал раунда» фиксирует ввод игрока, совпадение, колонки реального падения блоков и вмешательства генератора. После завершения раунда полный журнал и состояние поля сохраняются в браузере. Последние 20 сессий доступны в `window.__letterfallCompletedSessions`.

## Режимы игры

- **Скоростная печать** — единственный доступный игроку production-режим. Горизонтальное слово появляется сверху в случайной допустимой колонке и опускается вниз; два одинаковых слова не идут подряд. Его нужно ввести целиком до нижней границы. За достигшее низа слово отнимается одну жизнь; три жизни состоят из половинок. За каждую букву в пойманном слове начисляется 10 очков. Каждые 250 очков — новый уровень и небольшое ускорение падения. Раунд заканчивается на последней жизни, после чего можно сохранить никнейм в локальной таблице лидеров.
- **Звездопад** — существующий исходный режим для разработки: слова удаляют буквы на заполненном поле, а цель раунда — собрать звёзды. Он не выбирается игроком в production до следующего обновления.

### Бонусы жизни

Сердечко возвращает одну жизнь, половинка — половину. В панели разработчика настраивается предельная частота их появления: от одного бонусного слова на 5 до одного на 20 слов. По умолчанию бонус может появиться не раньше, чем на десятом слове после предыдущего, а затем дополнительно проходит случайную проверку — поэтому он остаётся редким.

### Тематические колоды

Перед каждой игрой можно выбрать тренировочную колоду: «Общие слова», «Технологии», «Кино» или «Дизайн и продукт». Тот же выбор доступен в панели «Для разработчика» во время локальной отладки; смена колоды начинает новый раунд. Каждая колода содержит до 500 коротких слов, но размер колоды игроку не показывается. В «Словобое: скоростной печати» порядок слов один раз перемешивается при старте: слова из одной колоды идут без повторов, а следующая перемешанная колода готовится, когда в текущей остаётся пять слов. Она включается только после завершения предыдущей, поэтому одинаковые слова не идут подряд и на границе колод.

## Яндекс Игры

Игра подготовлена для загрузки в Консоль Яндекс Игр:

- Production-режим скрывает панель разработчика; стартовый экран с выбором темы доступен в любом режиме.
- В production-режиме отключены журнал раунда, `console.info`-события и сохранение отладочных сессий.
- Звуковые эффекты создаются Web Audio API: в шапке есть выключатель звука и пауза; при паузе Яндекс Игр также останавливаются игра и звук.
- До показа кликабельного стартового меню игра блокируется собственным загрузочным экраном: `yandex-games.js` инициализирует SDK, определяет язык через `sdk.environment.i18n.lang` (русский — заявленный fallback), после чего в момент открытия меню однократно вызывает `LoadingAPI.ready()`.
- При нажатии «Сыграть ещё раз» игра вызывает полноэкранную рекламу SDK в безопасной точке между раундами; частоту показа определяет платформа.
- На окончании раунда игрок может осознанно авторизоваться через Яндекс ID и сохранить результат в общем рейтинге; поле никнейма при этом не показывается. Локальная таблица с никнеймом доступна только вне платформы — для локальной игры и отладки.
- Игровая поверхность не имеет системной прокрутки, выделения текста или браузерного контекстного меню; на телефонах она также защищена от long tap и запрашивает полноэкранный режим. Эти заготовки не означают мобильную поддержку текущего релиза: в Консоли выбирайте только десктопные платформы.

Перед загрузкой в Консоли создайте лидерборд с техническим именем `letterfall`, типом `numeric` и сортировкой по убыванию; на вкладке «Реклама» подключите монетизацию РСЯ. Для текущего релиза выберите только десктопные платформы. Затем соберите архив:

```sh
bash scripts/package-yandex-games.sh
```

Получится `dist/slovoboy-yandex-games.zip`; в его корне будет `index.html`. В Консоли укажите только русский язык и десктопные платформы, затем проверьте черновик через debug-панель: индикаторы Game Ready и языка должны стать зелёными при открытии меню. Отправку на модерацию выполняйте только после явного подтверждения владельца.
